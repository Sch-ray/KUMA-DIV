**项目起源**

KUMA-DIV项目基于 https://github.com/cifertech/ESP32-DIV 发展而来。主要有以下不同：

1、KUMA-DIV重新定义了所有的硬件连接，修复了一些引脚冲突，并重新设计了所有的PCB。

2、充分利用触摸屏优势，删减了物理按键，整体尺寸大幅缩减。

3、重新加入了RGB指示灯和蜂鸣器。

> [!IMPORTANT]
> 声明：设备仅用作专业人员的合法技术学习和合法分析测试（你最好知道你自己在干什么）。

**快速上手**

设备右侧有一个按键，短按一下可以打开电源，短按两下可以关闭电源。

设备顶部有两个指示灯，左侧是可以软件控制的RGBLED，右侧是充电指示灯（充电亮红色，充满灭）。

设备底部有一个TypeC口，可以用作充电和调试，内部集成有CH340芯片和ESP32自动下载电路。

顶部有6个天线口，这是他们的作用，你可以对照图片安装天线。
